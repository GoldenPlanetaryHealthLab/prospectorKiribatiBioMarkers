14  Curate Release

knitr::opts_chunk$set(eval = FALSE)

This page is the source of truth for the Kiribati biomarker release curation graph. Its target declarations are tangled into the DAG; it does not source an exported functions file. Source data remain under data/inputs/; only curated artifacts are written to data/outputs/curated/.

14.1 Initialize the root targets script

Before building the notebook pipeline, initialize the standard targets script from the repository root. The following call is shown for the operator to run there; it is deliberately non-executable in this manual.

# run this outside of the pipeline to establish targets use
targets::use_targets()

This is official {targets} functionality, not an artifact produced by the Manual’s emit profile. Confirm that _targets.R is available at the repository root before continuing. It is the project’s one target script: as the pipeline grows, edit it to add the notebooks in notebooks/pipeline/ that should participate in the pipeline. Do not create a second _targets.R under pipeline/.

Stage exactly one Golden et al. kiribati_cleandata_mergedHIES.csv export and one village_metadata CSV containing village, island, village_id, and rururb. The pipeline fails rather than arbitrarily choosing among multiple matches.

14.2 Curation rules migrated from the legacy vignette

The release derives age in months from interview date and date of birth, drops nonpositive derived ages, and replaces the source identifier with its MD5 digest. The small release retains only approved village_id and rururb; it does not contain literal community or island names. Thus the approved metadata, rather than this pipeline, supplies the non-reversible location key (i.e., the data remains non-identifiable outside of the pipeline operator).

Our simple pipeline takes the raw data and modifies required column names for release. No other major curation happens here.

Notably, this is separate from Manual operation — it doesn’t require a procedure block because it is a targets managed stage.

village_metadata_output_columns_vec <- c("village", "island", "village_id", "rururb")

We create a small function here to convert an identifier to a hash, preserving PHI.

hash_identifier <- function(identifier) {
  vapply(as.character(identifier), digest::digest, character(1))
}

14.5 Derive age and record source-quality evidence

Age derivation is separate from release shaping so the audit measures the same intermediate data used by both releases.

biomarker_ptx_age_df <- biomarker_ptx_raw_df %>% 
    mutate(
      dob = as_date(DOB_HIES, format = "%Y-%m-%d"),
      interview_date = as.Date(L1_q16_date_of_interview, format = "%d/%m/%Y"),
      age_in_months = interval(dob, interview_date) / months(1)
)

14.6 Construct the two de-identified releases

The slimmed release contains clinical measures and status fields. The small release joins approved non-identifying location metadata and omits literal community and island names.

biomarker_clean_df <- biomarker_ptx_age_df %>%
  filter(!is.na(age_in_months), age_in_months > 0) %>%
  transmute(
    uid = hash_identifier(hhld_id_hm_basic__id),
    hdl = L1_q61_hdl, ldl = ldl_corrected,
    tc = tc_corrected, pulse = pulse_corrected,
    glucose = glucose_corrected,
    triglycerides = triglycerides_corrected,
    systolic = systolic_corrected, diastolic = diastolic_corrected,
    temperature = temperature_correctedF,
    hemoglobin = hemoglobin_corrected, hematocrit = hematocrit_corrected,
    diabetes = diabetes_corrected, age_group = age_group,
    fever = fever, BloodPressure_status = BloodPressure_status,
    Glucose_status = Glucose_status, anemia_status = anemia_status,
    cholesterol_status = cholesterol_status,
    triglycerides_status = triglycerides_status,
    diabetes_status = diabetes_status, gender = gender_HIES,
    age_in_months
  ) %>%
  mutate(across(where(is.character), as.factor), uid = as.character(uid))
demog_clean_df <- biomarker_ptx_age_df %>%
  filter(!is.na(age_in_months), age_in_months > 0) %>%
  transmute(
    uid = hash_identifier(hhld_id_hm_basic__id), age_in_months,
    gender = L1_q3_gender,
    community = L1_q125_which_community_are_you_in,
    island = L1_q124_which_island_are_we_on
  ) %>%
  left_join(
    select(demog_ptx_village_raw_df, village, island, village_id, rururb),
    by = c("community" = "village", "island" = "island")
  ) %>%
  select(uid, age_in_months, gender, village_id, rururb) %>%
  mutate(across(where(is.character), as.factor), uid = as.character(uid))
